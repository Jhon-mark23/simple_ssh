## SIMPLE SSH SCRIPT 

install at your own risk

````bash
wget -O install.sh https://raw.githubusercontent.com/Jhon-mark23/simple_ssh/refs/heads/main/install.sh \
&& chmod +x install.sh \
&& sudo bash install.sh
````

after install type create to create ssh user
````
create
`````

# supported ports
SSH 22/80 
SSH SSL 443
SSH WS 8080
